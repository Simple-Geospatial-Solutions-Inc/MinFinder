# SGS MinFinder

## Design Context
Read before any UI work:
- `PRODUCT.md`: users, purpose, brand personality, anti-references, design principles (product register).
- `DESIGN.md`: visual system. North Star is "The Field Map" (AllTrails-style): floating white chrome on the map, bottom sheets for content, one gold pill per screen.
- Tokens live in `constants/colors.ts` and `constants/status.ts`; the shared kit (buttons, chips, sheets, lists, type scale) is `components/ui.tsx`.
